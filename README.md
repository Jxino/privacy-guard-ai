# Market Pulse

상품 판매량, 재고, 주문 흐름을 분석하는 이커머스 관리자 대시보드

## Tech Stack

spring-boot, java, jpa, mysql, analytics, ecommerce

## Main Features

- Sales summary aggregation API
- Inventory status endpoint
- Order trend analysis service

`http
GET /api/market-pulse
`
